# Slice brief: S15 — Zerops multi-repository checkpoint diff and truthful restore copy

Self-contained. Product rules are in `docs/spec-z3.md` §6.3–§6.4 and invariants Z3G-6/Z3G-7.

**Outcome**: Saved turn/full-thread diffs read every mounted Zerops repository and the UI warns
truthfully before restoring tracked/staged working changes.

**Allowed scope**
- Files: the existing `ZeropsCheckpointTargets` and `CheckpointDiffQuery` source/test pairs;
  `DiffPanel.tsx` plus new `DiffPanel.logic.ts/.test.ts`; `ChatView.tsx` and its logic/test pair.
- Explicitly excluded: commit/push/PR, working-tree/branch multi-repo status, remote mutation,
  untracked deletion, async restore completion receipt, contracts/RPC wire changes.

**Spec citations**: `docs/spec-z3.md` §6.3 (policy, keep untracked), §6.4 and Z3G-7 (fan-out,
host-prefixed merged diff, unchanged upstream fallback).

**RED test list**
- `diffAcrossTargets_twoRepositories_mergesHostPrefixedPatches` — layer: unit.
- `CheckpointDiffQuery_Zerops_turnAndFullThread_fanOut` — layer: integration.
- `checkpointDiffAvailability_selectedTurn_ignoresSingleRepoStatus` — layer: unit.
- `checkpointRestoreCopy_warnsAboutTrackedAndStagedWorkingChanges` — layer: unit.

**Protocol**: RED → GREEN → REFACTOR one behavior at a time with focused `vp test run` commands;
then affected server/web regressions and write-set lint/format.

**Report contract**: RED/GREEN outputs and exit codes, files, unit/integration pass lines,
independent oracle from literal unified patches and Z3G-6/Z3G-7.

**Stop conditions**: mutation/policy expansion; public contract change; path-prefix ambiguity;
scope drift; repeated unexplained failure.

**Definition of Done**: assertion RED replayed; two-repo and upstream paths green; DiffPanel no
longer blocks saved turn diffs on `/var/www`; restore warning is truthful; no outside write-set.

**Flow DNA / BUILD addendum**
- VERIFIED cites source; LOGICAL is explicit; UNVERIFIED stays named. Fix upstream, verify observed
  behavior, report all result states, and stop on silent-scope conditions.
- Never batch tests; RED → GREEN → REFACTOR. Expected values come from spec/known-good patches;
  assert public seams, use table-driven names where applicable, and report each touched layer.
