#### [CRITICAL] develop · STRUCTURED_PROSE — The 265-occurrence develop first-deploy response carries NO machine-readable next-step — it is pure markdown with empty top_keys
- **Claim:** Every develop:start response is emitted via textResult() as a single markdown string with no JSON structure: the agent gets no `status`, no `kind`, and no `nextCall` object — it must regex `zerops_deploy targetService="app"` out of prose to know what to call.
