# Slice brief: S5 — Restore public schema as the sole schema authority

**Outcome** (observable): runtime schema refresh, schema sync/check, the derived
version snapshot, and scheduled CI consume only the public `/settings` schemas;
none resolves credentials or queries service-type ACTIVE state.

**Allowed scope**
- Files: schema CLI/cache/sync and tests; the narrow platform ACTIVE method and
  mocks; schema workflow; catalog snapshot path/comments; schema ownership docs.
- Explicitly excluded: a replacement availability checker, platform mutation,
  Local Storage provisioning, deploy behavior.

**Spec citations**: `docs/schema-integration.md` §Schema freshness and drift
policy; `docs/spec-knowledge-architecture.md` §3.1.

**RED test list**
- `TestSchemaCheck_DoesNotResolveCredentials` — layer: unit
- `TestSchemaCommands_PublicOnlyHaveNoCredentialOrActiveStatusDependency` — layer: unit
- `TestSchemaDriftWorkflow_MainOnlyUsesPublicSchemaAndStrictMode` — layer: integration
- `TestCache_PublicSchemaServiceTypesRemainUnfiltered` — layer: unit

**Protocol**: RED → GREEN → REFACTOR.
1. Run `go test ./cmd/zcp -run 'Schema(Check|Commands|DriftWorkflow)' -count=1 -v` and observe credential/provider assertions fail on the old implementation.
2. Remove the ACTIVE overlay from every schema path and platform interface, then rerun the named tests.
3. Run tokenless sync/check, independent live/embedded hash comparison,
   `make test-race`, `make lint-local`, `make vet-tags`, and `make e2e-zcp-fast`.

**Report contract**
- RED: provider called once; forbidden ACTIVE symbols and workflow secret detected.
- GREEN: named tests pass; tokenless real binary prints `schema check: OK`.
- Independent oracle: canonical SHA-256 of both downloaded public JSON documents
  equals the corresponding embedded document.

**Stop conditions**: scope drift · a material unknown · an acceptance-criteria
change · a repeated unexplained check failure.

**Definition of Done**
- [x] RED failed for the intended credential/ACTIVE dependencies.
- [x] Named tests pass with `-count=1 -v`.
- [x] `make lint-local` clean.
- [x] Public schema hash comparison passes without a token.
