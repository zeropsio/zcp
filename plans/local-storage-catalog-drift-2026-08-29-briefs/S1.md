# Slice brief: S1 — Local Storage core tracer bullet

Self-contained: no other plan file is required to execute this. The cited spec
sections are the authority for behavior.

**Outcome** (observable): a schema carrying `local-storage:single@1` accepts it
as first-class managed Local Storage, the agent catalog renders that exact
identifier, bootstrap validation accepts it, and env readiness does not expect
database-style connection variables.

**Allowed scope**
- Files: `internal/topology/predicates.go`, `internal/topology/type_equivalence.go`, `internal/topology/types_test.go`, `internal/topology/type_equivalence_test.go`, `internal/topology/runtime_class_test.go`, `internal/schema/catalog.go`, `internal/schema/local_storage_test.go`, `internal/workflow/validate_test.go`, `internal/knowledge/catalog_view.go`, `internal/knowledge/versions_format.go`, `internal/knowledge/versions.go`, `internal/knowledge/versions_test.go`, `internal/tools/workflow_checks.go`, `internal/tools/workflow_checks_test.go`
- Explicitly excluded: generated schema/catalog artifacts; bundle, authoring,
  Data Console, CI workflow, live provisioning, and any bare
  `local-storage@1` alias.

**Spec citations**: `docs/schema-integration.md` §What schemas/§Where we use it;
`docs/spec-knowledge-architecture.md` §3.1; `docs/spec-workflows.md` §2.3-§2.4.

**Protocol**: RED → GREEN → REFACTOR.
1. Write one named test first and confirm it fails for the intended assertion
   (a new public predicate may first produce a missing-symbol RED, but must get
   a minimal assertion-level RED before behavior is implemented):
   `go test ./internal/topology ./internal/schema ./internal/workflow ./internal/knowledge ./internal/tools -run 'LocalStorage' -short -count=1 -v`
2. Implement only enough for that test to pass; repeat one test at a time.
3. Refactor with tests green; rerun the command and then `make lint-fast`.

**BUILD addendum**
- Never batch-write tests: RED → GREEN → REFACTOR one named test at a time.
- Independent oracle: expected values come from the spec section or the
  known-good literal `local-storage:single@1`, never from production helpers.
- Assert on public seams only (`topology`, parsed `schema.Schemas`, workflow
  validation, formatted catalog output, and tool readiness output).
- Use table-driven `Test{Op}_{Scenario}_{Result}` naming and report one
  layer-matrix pass line per touched CLAUDE.md layer.
- `make lint-fast` must be clean before reporting done.

**Report contract** (all required — never summarize away a failure)
- RED output + exit code for every named test
- GREEN output + exit code
- Files touched (exact list)
- Layer-matrix pass lines (unit, integration, tool)
- Independent-oracle note confirming the exact live identifier is a literal

**Stop conditions**: scope drift; any evidence that Local Storage has HA,
profiles, or generated connection envs; acceptance-criteria change; repeated
unexplained check failure.
