# Slice brief: S3 — Refresh schema and catalog artifacts

Self-contained: no other plan file is required to execute this. The cited spec
sections are the authority for behavior.

**Outcome** (observable): all committed generated schema/catalog artifacts come
from one authenticated current-platform fetch, contain the active Local Storage
types, and the real live all-types audit accepts every active identifier.

**Allowed scope**
- Files: `internal/schema/testdata/zerops_yml_schema.json`, `internal/schema/testdata/import_yml_schema.json`, `internal/knowledge/testdata/active_versions.json`, `internal/schema/catalog_test.go`, `internal/schema/schema_test.go`
- Explicitly excluded: hand-editing generated JSON, platform mutation,
  application logic, CI workflow, or introducing types absent from the fetch.

**Spec citations**: `docs/schema-integration.md` §What schemas and §Code locations;
`docs/spec-knowledge-architecture.md` §3.1.

**RED test list**
- `TestEmbeddedSchemas_LocalStorageSingle_Present` — layer: unit
- `TestEmbeddedSchemas_LocalStorageVolumeFields_Present` — layer: unit
- `TestCatalogManagedBaseNames_LocalStorage_Present` — layer: unit
- `TestLiveAllTypesAudit` — layer: integration (existing API-tag oracle)

**Protocol**: RED → GREEN → REFACTOR.
1. Add only one named artifact assertion first and confirm it fails. The volume
   assertion must validate `run.volume.hostname`, `mountPath`, and `readOnly`
   through the parsed/structure-validation public seam:
   `go test ./internal/schema -run 'LocalStorage|CatalogManagedBaseNames' -short -count=1 -v`
2. Run the repository's authenticated `make schema-sync` generation path; do
   not edit JSON manually. Inspect the diff for scope and secrets.
3. Rerun unit tests, then
   `go test -tags api ./internal/schema -run '^TestLiveAllTypesAudit$' -count=1 -v`,
   followed by `make lint-fast`.

**BUILD addendum**
- Never batch-write tests: RED → GREEN → REFACTOR one named test at a time.
- Independent oracle: the live `/settings` schemas plus authenticated ACTIVE
  service-type response are the source; no expected artifact is synthesized
  from committed data.
- Assert through parsed `schema.Schemas` and the live audit, not raw helper state.
- Use `Test{Op}_{Scenario}_{Result}` naming and report one layer-matrix pass line
  per touched CLAUDE.md layer.
- `make lint-fast` must be clean before reporting done.

**Report contract** (all required — never summarize away a failure)
- RED output + exit code
- GREEN output + exit code, including API-tag audit
- Exact files touched and generation command
- Layer-matrix pass lines (unit, integration)
- Independent-oracle note and confirmation that no credential entered the diff

**Stop conditions**: unauthenticated/invalid fetch; upstream drift beyond the
expected current schemas and ACTIVE snapshot that changes scope; any secret in
output/diff; repeated unexplained check failure.

**Definition of Done**
- [ ] RED replay fails at slice base and passes at slice head
- [ ] Named tests pass with `-count=1 -v`
- [ ] `make lint-fast` clean
- [ ] No file outside Allowed scope touched
- [ ] Report contract filled in full
