## Summary
1. The Zerops GUI is a desktop-only, two-pane app: a fixed 480px "controls pane" of stacked flat cards on the left (org pill + ⌘K pill + notifications float over it at top:25px, 40px tall) and a max-1600px "content pane" on the right (search field, sort pill, card/list toggle); `<meta viewport width=1200>` and zero app-shell media queries mean phones get a scaled desktop (screens 12/13 confirm). Each pane owns its own OverlayScrollbars `zef-scrollbar`; body never scrolls.

2. Colour is tone-on-tone, not elevated: page #eceff3 → card #f3f5f7 → white tiles/pills; no card shadows by default (only popovers/dialogs get the grey-tinted `c-soft-elevation` triple shadow). Brand teal #00ccbb is confined to the logo pill, badges and focus tints; the ACTION colour is Material blue #0077cc (primary buttons, selected-card 2px outline, links). Dark theme is a graphite-green ramp (#0c0f0e/#141918/#1b2220/#1e2624, text #e9eeec/#9faea9/#5e6e69) with mint #00e5c0 as the single accent. Live token dump (416 vars) confirms light values; dark values come from source.

3. Type is Roboto (300–900) + Roboto Mono + DejaVu Sans Mono (self-hosted), Material Icons filled+outlined — all confirmed loaded live; Open Sans is declared (`--font-alt`) but never loaded. The signature micro-typography: 8–10px uppercase 500/600 labels with 0.5px/.06em tracking, 20px/500 hostname with `:port` at .6 opacity, `.u-desc` 13px/1.75/.7.

4. State vocabulary = coloured dot (Material 400-level palette per status) + tiny uppercase label + pulse/ripple for in-flight; tinted pill chips (green access, purple region, blue tag, white info-chips); process steps as 17px bordered circle icons on a 30px grid; error surfaces #fdefef/#ffe3e3.

5. Agent continuity to keep: the mint `#e8f7ec` zagent panel (four white flat pills Web Terminal/SSH/Cloud IDE/Desktop IDEs, edge-to-edge auth tray with monochrome `currentColor` provider marks, "AUTHORIZED" 10px/600 uppercase in #2e7d32 with haloed dot, unauthorized #b26a00 pulsing), and the auth dialog's 400px stepper column + terminal. Material legacy leftovers (pill buttons, white dialog scrim, indigo mini-card, infinite pulse/ripple/bounce animations) need not be inherited — the last conflicts with T3's no-continuous-repaint rule.

## 10. Design DNA

**Recognisably Zerops (five traits):** (1) a cool grey canvas `#eceff3` with flat tone-on-tone cards `#f3f5f7` and white tiles — depth by tint, never by shadow; (2) Roboto with a rigid micro-label grammar — 8–10px uppercase 500/600 tracked labels beside 20px/500 names, the `:port` suffix at .6, and small-cents prices; (3) status as a coloured dot + tiny uppercase word, with pulse/ripple meaning "in flight", and a fixed semantic tint set (green `#e8f7ec` ready, orange `#fff4e0` needs-you, red `#fdefef` failed, blue `#eff9fd` running); (4) pills everywhere — 40px teal-tinted org pill, ⌘K pill, sort pill, white flat pills inside green panels, 10px-radius tinted chips (green access / purple region / blue tag / white info-chip); (5) blue `#0077cc` as the action and selection colour (2px outline on the active card, primary CTAs, links) with teal reserved for identity, and a graphite-green dark theme with mint `#00e5c0` as its only accent.

**Incidental legacy a new product need not inherit:** Angular Material legacy buttons with `!important` pill overrides and 38px line-heights; the white dialog scrim; `z-manual-elevation` shadow hacks; the 480px fixed column + `width=1200` viewport; per-component `::ng-deep` colour patches and the `--z-<light>-<dark>` twin-named token scheme (416 vars, many single-use); Material palette-level status colours (100/200/300/400) that collapse to four hues; infinite pulse/ripple/bounce/shimmer animations; the indigo control-plane header; three different monospace stacks; the snake game; Open Sans declared but unused.

**Mapping note for z3 (INFER):** z3's `apps/web/src/index.css:1388-1500` already exposes shadcn-style tokens (`--background/--card/--popover/--primary/--accent/--border/--sidebar-*`, dark via `@variant dark`, `--radius .625rem`, `--font-sans` system stack, `--font-mono`). A Zerops skin = `--background #eceff3`, `--card #f3f5f7`, `--popover #fff`, `--primary #0077cc`, `--accent` teal tint `rgba(0,204,187,.13)`, `--border rgba(0,0,0,.08)`, `--success #00cc55`, `--warning #ffa726`, `--error #cc0011`; dark `--background #0c0f0e`, `--card #141918`, `--popover #1e2624`, `--foreground #e9eeec`, `--muted-foreground #9faea9`, `--primary` mint `#00e5c0` on `rgba(0,229,192,.14)`; `--font-sans` Roboto, `--font-mono` Roboto Mono.
