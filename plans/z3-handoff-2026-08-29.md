## 5. Rules that were paid for on day 2 (keep them)

- A "clean" git merge can silently DUPLICATE a contract block two branches added at different anchors — grep for
  duplicate `export const` after every parallel-contract merge.
- The container-served client boots hosted-static only with `VITE_HOSTED_APP_CHANNEL` ∈ {`latest`, `nightly`};
  any other value falls to `/pair` without an error.
- Presence of a credential file is not authentication (upstream's Claude probe says "authenticated" after logout);
  verify with the CLI's own status command.
- The zcp validator requires the OS prefix in runtime types (`ubuntu/nodejs@22`) and the mode inside managed types
  (`postgresql:single@16`).
- Effect in this fork: `FileSystem.watch` + scope closure crashes the scheduler; nested retry after `Stream.debounce`
  gives up; `it.layer(NodeServices.layer)` merges a `TestClock` (`excludeTestServices: true`); `Layer.mergeAll` does
  not chain dependency resolution like `provideMerge`.
- Parallel slices: one worktree per slice from `main`, merge `main` into the slice before its final report, the
  orchestrator merges into `main`, the zone test + `imported.lock --check` + package typechecks run on `main` after
  every merge; the ledger has one writer.
