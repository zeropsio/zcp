**Your git host.** `$GITEA_URL` is the account's Gitea, `$GITEA_TOKEN` is an access token minted for you alone (scope `write:repository`: git works, `/user` and `/admin` answer 403), and `$GITEA_REPO` is the repository this environment develops. Pass the token inline on a push; never write it into `.git/config`. What ships code to the group's other projects is `.gitea/workflows/` in that repository — read it before assuming how those deploys happen, and look at what the remote already holds before a push that would replace it. Deploys within this project follow the ZCP workflow's guidance, not the pipeline.
