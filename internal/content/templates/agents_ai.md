**AI in the app.** An AI feature in the person's app runs on the organization's key from `zerops_env action="ai-key"`, never a key of your own or one asked of them. Each service that calls the model reads it in its `run.envVariables` as `OPENAI_API_KEY: ${NEBIUS_API_KEY}` and `OPENAI_BASE_URL: ${NEBIUS_BASE_URL}`, which any OpenAI SDK reads by itself (Token Factory is OpenAI-compatible). Pick the model from `GET $OPENAI_BASE_URL/models` run inside the service and keep its id in one place. Never print, log or commit the key. With no key yet, say so: an Owner or Admin sets it in Mate's settings as the organization's Model key.
