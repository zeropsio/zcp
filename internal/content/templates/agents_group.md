**Your group.** `$MATE_GROUP` names the project this environment belongs to; `$MATE_ENVIRONMENTS` is the rest of that group as JSON — role, name, project id and the services each one runs. That listing is the only view you have of them: this container's token is scoped to THIS project alone, so `zerops_*` and `zcli` cannot read a sibling, and a sibling's absence from those tools is not evidence it does not exist. Read the listing before you provision anything — the group may already run what you were about to build. Code reaches another environment through the repository's pipeline, never from here.
