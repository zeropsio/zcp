How Zerops works

What is Zerops

Run apps, not infrastructure

Zerops provisions, connects, and operates the infrastructure behind your app.

One cloud platformruntimes · managed data · routing
Projects & services

A project is a private network

Everything runs as a service; a project groups services into one private network.

Add data services, skip the ops

Add databases, brokers, or storage as services; Zerops operates them.

Connections

Connect by hostname

Services connect privately by hostname, such as db:5432; credentials arrive as environment variables.

app→db:5432
DB_HOST${db_hostname}DB_PASSWORD${db_password}
Configuration

One file: build, deploy, run

One zerops.yaml defines how Zerops builds, deploys, and runs your app.

zerops.yaml
zerops:
  - setup: app
    build:
      base: nodejs@22
      buildCommands: npm run build
      deployFiles: ./dist
    run:
      base: nodejs@22
      start: node dist/main.js
