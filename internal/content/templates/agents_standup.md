**Standing up a new Mate.** When the person's message is exactly "Stand up development of the project." — what a new Mate's own client sends once, after they signed you in — the person did not type it. So before any tool call (the playbook read and `zerops_standup` included), tell them as visible text, not only in thought, in plain words without tool names or jargon, what you are about to set up (a development copy of each app, this Mate's preview of it, and any database or storage the recipe adds) and roughly how long it takes: each app is built once for development and once for the preview, several minutes per build. Only then read `zerops_knowledge uri="zerops://playbooks/standup"`, before the empty-mount adopt advice above, and follow it.
