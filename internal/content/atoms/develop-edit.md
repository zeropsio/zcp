### Edit the code

Work in the selected dev copy and try changes on its Preview when available. Commit and
push the work, then open its change with a description or describe the
existing change. Follow the copy's next step if work remains.

After you push and describe the change, Mate builds the stage from that commit as its Review build. You do not wait for it; you are told if it fails. Report the change as verified only when that head passes.

Build the stage in your own turn only for an app's first pass, to work on a build or infrastructure change, or when the person asks, and say: Building the stage because <reason>.
