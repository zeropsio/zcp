### Edit the code

Work in the selected dev copy and verify the draft. Commit and push the work, then open its change with a description or describe the existing change. Follow the copy's next step if work remains. Describing does not build the stage: adding the draft starts the build. If the add fails, read the failure, fix and verify in the same draft, commit and push; zcp builds again automatically. If HQ gives up after the tries, ask the person what is needed.
