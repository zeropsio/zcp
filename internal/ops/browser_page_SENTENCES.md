# The page a browser call opened (`browser.go`, `browser_warm.go`)

- BP-DEVSUP — A browser call whose page is the dev-server supervisor's own holding page fails as a call in that page's words: a server that is coming with the call that waits for it, one nothing will start with the call that reads its exit and log; a page without the mark is the app's. Breaks: an agent is told to read logs and fix a server that is only starting, or takes the holding page's picture for its app.
- BP-SKIP — After a caller's step runs and fails, later caller steps say they were not run because of that failure; a refused command comes first and does not stop the rest, and closing reports still run. Breaks: an agent waits on actions that could not have happened or loses a walk to a refused command.
- BP-PAINT — A page that paints while its load never finishes can be walked as soon as it paints. Breaks: an agent spends the open's load timeout on a page it could already use.
- BP-FAILED — A wait on a page that has already thrown an uncaught error or answered 5xx for a document or script fails with that cause; another request's 5xx and a script's 4xx do not end it. Breaks: an agent spends a wait's full timeout on a page that has already failed.
- BP-OPENBOUND — An open that never commits has its own bound, reports the failed open and diagnoses an answering server; an unanswered server keeps the wedge verdict and skips caller actions while the walk attempts paint and closing reports. Breaks: an agent spends the entire call waiting for response headers and gets no page diagnosis.
- BP-OBSERVER — A walk can still open and inspect its page when its tab's optional DevTools observation cannot be started. Breaks: an agent loses the whole walk because the page observer could not start.
