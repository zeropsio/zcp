# Bootstrap runtime URL guidance

- BG-URLS — Bootstrap identifies a Mate's stage and points to a draft in Mate without handing the stage back; standalone runtime URL guidance remains unchanged, including when no URL is resolved.
- BG-RECIPE — In a Mate the recipe import YAML of the discover and provision guides is preceded once by the note that its stage is where the Review build builds an added change and never the person's draft; standalone the guide is unchanged. Breaks: the agent hands the stage back as the person's preview because a recipe comment calls it one.
