# The version a stage runs (`compute_envelope.go`, `envelope.go`)

- VER-STATES — On a Mate's envelope a pair's stage carries its ACTIVE version's id and created time, with the whole commit (SHA-1 or SHA-256) a commit deploy named it by, and without a commit when no commit deploy did: a Review build's candidate, or a version named by its commit outside zcp; an older ACTIVE version is carried even when a newer one is still building or failed. A stage with no ACTIVE version holding code, a read that fails or does not return that version, and an envelope that is not a Mate's all carry no version, and the rest of the envelope stays as it was. Breaks: the Mate shows a build in flight as running, a Review build's candidate hash as the commit a stage runs, a version on a stage that runs none, or a version on the envelope of a zcp outside a Mate.
- VER-WIRE — A stage's version marshals as exactly `id`, `commit` and `at` under `version`, with `commit` left out when the version has none; a snapshot without a version carries no `version` key. Breaks: the Mate's decoder finds no version under a renamed or extra key.
