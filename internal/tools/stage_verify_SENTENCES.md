# Stage writers and verification

- SVF-IDENTITY — A Mate's stage verify identifies a stable active version and its clean commit, says when it is not the caller's last deploy, and reports an unreadable or moving version without attributing the check to it.
- SVF-COMMIT — A version name identifies a commit only when its second word is a clean hexadecimal short or full SHA.
- SVF-TARGETS — A push orders every anticipated build target, or its source when it has no anticipated target.
