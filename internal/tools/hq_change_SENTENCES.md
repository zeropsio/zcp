# Develop guidance on a repository's branches (`hq_change.go`)

- DG-OPEN — At develop's start the open changes' line takes a change's branch in a plain pair's dev service only when the copy planner lets its checkout move; otherwise it names the checkout occupied, or unknown with the read it lacks, and a dev pool acquires a lease. Breaks: an agent switches the branch under another conversation's uncommitted or unhanded work.
- DG-NEWWORK — At develop's start new work is cut from an up-to-date main in a plain pair's dev service only on the same answer, with the planner's occupied or unknown words otherwise, and in a dev pool by a lease. Breaks: an agent checks main out over another conversation's work to start its own.
- DG-MERGED — A merged change's note brings main up to date in a plain pair's dev service only when the copy planner lets its checkout move, with the planner's words otherwise, and in a dev pool cuts the next branch by a lease. Breaks: the merge note checks main out over another conversation's work.
- DG-HANDED — A change handed from a gone Mate is taken, or cut from main when nothing is pushed to it, in a plain pair's dev service only when the copy planner lets its checkout move, with the planner's words otherwise, and in a dev pool by a lease. Breaks: taking a handed change moves another conversation's copy.
- DG-SINGLE — On an HQ that keeps one open change per repository, the open change's branch is taken — or an older zcp's branch renamed onto it — in a plain pair's dev service only when the copy planner lets its checkout move, with the planner's words and no rename otherwise, and in a dev pool by a lease. Breaks: the single change's line or the open-change answer moves another conversation's copy.
- DG-READ — The checkout these lines ask about is read for the call as where reads it: a clean main with nothing unpushed may move, main with an unpushed commit or uncommitted work is occupied, a clean branch whose head origin's main holds may move, one with a commit main lacks is decided by its handover, and a checkout that did not answer is unknown. Breaks: a line decides on a checkout state this call never read.
- DG-OWN — Every develop line that switches a plain pair's dev checkout — the open changes' take, new work from main, a merged change's note, a handed change's take and cut, the single change's take and an older zcp's rename, open-change's take of the change it holds, the realignment's cut — gives its git when the copy planner finds the checkout free or holding only the Mate's own work (a branch whose head main holds, the branch the line takes, the branch whose work it carries, the merged branch at the head HQ landed), and withholds it while another conversation's unhanded work occupies it. Breaks: a line moves another conversation's work, or sends the agent to ask the person about the Mate's own.
